QOpenHD Advanced menu — ADVANCED SETTINGS ON

Scope: this local QOpenHD checkout and adjacent OpenHD firmware source, 2026-10-28.
Parameter reference: 290 fallback definitions + 49 additional firmware IDs + generated families.
Fixed options/ranges are expanded below. Hardware-specific options remain explicitly dynamic.
Air/Ground/camera membership and metadata are supplied by the connected firmware; this is not a live-device export.

Advanced switch effects:
  - Disable all hidden/whitelist filtering in parameter models, including per-card TX power and CARD_TYPE_* diagnostics. Actual rows still depend on parameters reported by Air, Ground and each camera.
  - Expose SENSOR_MODE and LIBCAMERA_IMPL camera rows when reported.
  - Expose the separate frame-rate selector in the resolution editor.
  - Extend Air and Ground power sliders to 150%.
  - Expose ESP analysis, FHSS controls and link usage diagnostics, subject to parameter availability.
  - Instantiate Show Retransmission Stats widget control.
  Separate switches: Allow frequency change when armed, Show all wifi channels, Show link routing, Show link usage
